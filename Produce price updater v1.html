Iqbal Foods – Weekly Produce Price Updater

Match ERP codes, calculate +25% from RSP, apply the X.X9 rounding rule, compare against online prices, and create both upload and review files.

ERP code = column A. RSP = column H. The weekly file should contain the normal retail columns A–I; J–M are generated by this app.
ERP code = column P. Online price = column F. Discount = H. Discount Start = I.
Choose both Excel files to begin.

Browser-only processing
The Excel files are read and processed locally in your browser using JavaScript. No Excel data is sent to GitHub or to a processing server. GitHub Pages only hosts this webpage and its JavaScript library.
Matching is done by ERP code only. All online rows with a matching ERP code are updated. Nothing else in the online workbook is intentionally changed.
